# Communication Preferences

- Communicates in Chinese and wants user-facing text/menus in Chinese; when asking for AI prompts/skill content, often specifically wants an English version. Confidence: 0.85
- Frequently asks for generated commands/prompts to be copied directly to the clipboard ("直接复制到我的剪切板"). Confidence: 0.7
- Prefers diagnosing by pasting concrete logs/commands and pointing to specific servers/devices rather than generic descriptions. Confidence: 0.7
- Reports bugs as numbered lists of observed symptoms (including which UI evidence contradicts the seeming conclusion, e.g. "stop button is still showing so it likely hasn't finished") and asks for root-cause investigation ("排查一下…看看是为啥") rather than an immediate fix; often explicitly forbids touching code until the cause is found ("不要改代码，先排查") and wants a thorough investigation of the whole relevant path ("全面地排查一下"). Confidence: 0.75
- Pings mid-task with short status checks ("搞定了吗", "修好没有？", "排查出来为什么了吗？"), sometimes repeating the same question while the work is still running, and expects a direct done/not-done answer — including an honest "not yet" with the current blocker and what has actually been verified — instead of a long narrative or an implied completion. Confidence: 0.65
- Gets openly impatient when long-running work (e.g. a release) runs far past the expected time, asking what the agent is even doing and pointing back at the existing workflow ("干了三十分钟了都没干好，不是有部署流程吗") — so they want proactive progress reporting while a long task runs, not a silent wait, plus a concrete accounting of where the time went if it overruns. Confidence: 0.6
