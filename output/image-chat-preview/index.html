与现有对话页的差异

区域现有对话页生图模式
会话列表 / 连接条 / 附件 / 下载 / 通知保留完全复用，不另做页面
模型选择按钮输入区工具栏保留在同一位置（图标 + 模型名 + 下拉箭头）
思考块 / 工具卡片 / 统计行 / 复制按钮对话必需隐藏
待发送队列条对话必需隐藏（生图单轮）
参数（尺寸/张数/质量/格式）只能写在文本里（--size 等）参数条点选，并回显在进度卡片
参考图附件即输入显式参考图区，决定走图生图
结果呈现单张图 + 文字自适应网格（1/2/4）+ 放大/保存/继续改/复制提示词
历史参与整段会话都发给模型只发本次输入（需配合 opencode 修复）

图标全部为线性 SVG（相框/星芒/箭头/下载/编辑/复制/关闭/停止），不使用 emoji。 实现顺序：① 修 opencode 生图取历史的问题；② 客户端模式检测 + 参数条 + 结果网格；③ 参考图与「继续改」。
