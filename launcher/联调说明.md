# Launcher 联调说明

## 目标

验证 `launcher` 的 machine 级直连链路：

1. launcher 本地启动成功
2. launcher 通过 websocket 直连后端
3. 后端可按 `machineID` 获取 launcher 状态
4. 后端可触发 launcher 升级/回滚

## 运行原则

正式使用时：

1. 只启动 `launcher`
2. 不再把 `relay.sh` 作为正式启动入口
3. agent 由 launcher 统一创建、启动、重启、删除

`relay.sh` 只建议保留作历史调试脚本，不再作为设备正式运行路径。

## 前置条件

1. 后端已启动
2. 已有可用操作员账号
3. 已拿到该操作员的 `operator_key`
4. 本机已安装可执行的 `opencode`

## 1. 启动后端

在目录 `backend/` 下执行：

```bash
go run ./cmd/server
```

默认本地地址：

```text
http://127.0.0.1:8080
```

## 2. 登录获取 operator_key

```bash
LOGIN=$(curl -s http://127.0.0.1:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123456"}')

TOKEN=$(node -e 'const data=JSON.parse(process.argv[1]); console.log(data.access_token);' "$LOGIN")
OPERATOR_KEY=$(node -e 'const data=JSON.parse(process.argv[1]); console.log(data.operator.operator_key);' "$LOGIN")
echo "$OPERATOR_KEY"
```

## 3. 启动 launcher

在目录 `launcher/` 下执行：

```bash
OPENCODE_RELAY_OPERATOR_KEY="$OPERATOR_KEY" bash start.sh
```

可选环境变量：

```bash
LAUNCHER_PUBLIC_BASE=https://www.xyapi.top/codex
LAUNCHER_RELAY_URL=ws://127.0.0.1:8080/ws/device
OPENCODE_RELAY_OPERATOR_KEY=<你的 operator_key>
```

说明：

1. 默认会从 `LAUNCHER_PUBLIC_BASE` 推导 websocket 地址
2. 默认会自动生成并持久化 `machine_id`
3. 只有开发联调时才建议手动覆盖 `LAUNCHER_RELAY_URL`

预期结果：

1. 终端打印 `launcher listening on http://127.0.0.1:4071`
2. 后端日志出现 launcher 连接记录
3. 设备详情可看到该 machine 在线

## 4. 查看设备列表

```bash
curl -s http://127.0.0.1:8080/api/devices \
  -H "Authorization: Bearer $TOKEN"
```

记下返回里的 `machine_id`。

## 5. 获取 launcher 状态

```bash
curl -s http://127.0.0.1:8080/api/devices/<MACHINE_ID>/launcher \
  -H "Authorization: Bearer $TOKEN"
```

预期结果：

1. 返回 `state.status`
2. 返回 `state.current_version`
3. 返回 `state.agent_count`

## 6. 触发 launcher 升级

```bash
curl -s http://127.0.0.1:8080/api/devices/<MACHINE_ID>/launcher/upgrade \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"target_version":"0.1.0"}'
```

说明：

1. 如果本地 `versions/0.1.0` 不存在，会走下载流程
2. 如果下载源当前版本不是目标版本，会返回错误

## 7. 触发 launcher 回滚

```bash
curl -s http://127.0.0.1:8080/api/devices/<MACHINE_ID>/launcher/rollback \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{}'
```

## 8. 本地直查 launcher 服务

```bash
curl -s http://127.0.0.1:4071/state
curl -s http://127.0.0.1:4071/versions
```

## 9. 常见问题

### 1. 提示缺少 `LAUNCHER_OPERATOR_KEY`

说明没有把 operator_key 传给启动脚本。

### 2. `/api/devices/{machineID}/launcher` 返回无权限或离线

检查：

1. launcher 是否已成功启动
2. `LAUNCHER_OPERATOR_KEY` 是否属于当前登录用户
3. 删除 `~/.my-opencode-launcher/machine_id` 后重新启动，确认是否生成了稳定的设备 ID

### 3. 升级失败

优先检查：

1. `/api/cli/version` 返回的版本是否与目标版本一致
2. 下载包是否存在
3. `sha256` 是否匹配
