# Flutter 控制台开发框架

## 目标

构建一个可扩展到多机多 `agent`、多操作端的控制台前端。

前端不是聊天页，而是控制台。

## 一级导航

第一版固定为 5 个模块：

1. 总览 `Dashboard`
2. Agents
3. Tasks
4. Sessions
5. Approvals

## 第一模块

第一模块名称：

- `ConsoleShell + Agents`

本模块目标：

- 建立控制台响应式壳层
- 建立桌面 / 平板 / 手机三种导航形态
- 接入真实 `GET /api/agents`
- 完成在线 `agent` 列表展示

## 响应式规则

### Desktop

- 左侧固定导航
- 中间列表区
- 右侧详情区

### Tablet

- 左侧窄导航
- 中间列表
- 详情抽屉

### Mobile

- 底部导航
- 列表页与详情页分屏

## 目录结构

```text
lib/
  app/
  core/
  modules/
    dashboard/
    agents/
    tasks/
    sessions/
    approvals/
  shared/
```

## 第一阶段技术约束

- 使用 Flutter Web 先完成桌面端控制台
- 使用响应式布局，不做单页聊天样式
- API 先接 HTTP
- 任务详情流后续接 SSE

## 第一阶段数据源

- `/api/agents`

## 第一模块验收标准

- Web 可启动
- 页面根据宽度切换布局
- 可成功请求 `/api/agents`
- 可显示 `agent_id`
- 可显示 `machine_id`
- 可显示 `project_id / root`
- 空状态和错误状态可见
