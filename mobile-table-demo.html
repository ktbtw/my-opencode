5.x 符号兼容性

桌面端保持表格，移动端自动切换为可扫描的行卡片。

符号 5.x 全系列可用？ 说明
socket_create_kernel_bind/kernel_listen/kernel_accept 是 很早就存在的标准导出符号。
kernel_sendmsg/kernel_recvmsg/sock_release 是 与上一组相同，属于长期稳定接口。
sock_alloc_file/kernel_setsockopt 是 移动端优先保证代码字段可读，不再被窄列逐字符撑高。
长符号单行展示代码区域只在自身内部横向滚动。
移动端行卡片每行独立，字段标签清晰，避免三列被压扁。
桌面端不变形宽屏继续使用传统表格，方便对照阅读。
