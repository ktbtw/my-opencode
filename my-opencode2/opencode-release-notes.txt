- 修复被强杀的 git 留下 index.lock 后快照持续失败的问题：索引写入遇到锁冲突自动退避重试，超过 10 秒的陈旧锁自动清理后再重试
- 修复非媒体附件导致任务直接失败的问题：模型不支持的附件不再作为 file part 透传（OpenAI 兼容供应商会抛 UnsupportedFunctionalityError），文本内容改为内联，其他一律降级为中文提示
- 修复历史遗留的 application/octet-stream 文本附件持续污染会话、导致该会话后续每轮对话都失败的问题
- 附件无法映射成模型输入类型时不再放行，避免整个请求被供应商错误中断
- 修复任务完成结果选择逻辑：优先发送最终 assistant 回合正文，缺失时回退流式正文，不按长度或关键词裁剪用户内容
- 对话中的回复、同步、恢复和等待状态统一显示在正文下方的轻提示，不额外堆叠独立状态栏
- 活动任务历史按任务索引分页读取，避免恢复时扫描完整会话和子会话
- 完成事件与流式正文保持顺序，超大正文不会阻塞终态发送
- 修复快照误收录运行时数据库、构建缓存和大型生成文件导致 Git pack 无限膨胀的问题
- 清理快照前检查正式 pack 与松散对象的磁盘空间，空间不足时跳过 GC，避免再次生成巨型临时 pack
- 迁移旧快照索引时自动移除运行时文件和超限生成文件，仅修改快照索引，不删除工作区文件
- 活动任务使用索引分页恢复正文和工具历史，避免逐页重建完整会话及子会话
- 移除完整显示日志的常驻内存缓存，单任务历史读取按任务索引查询
- 保持正文、思考、工具、插入消息的顺序与持久化游标，兼容旧日志迁移
